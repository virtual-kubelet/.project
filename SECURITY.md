# Security Policy

## Reporting Security Issues

The Virtual Kubelet maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/virtual-kubelet/virtual-kubelet/security/advisories/new) form.

For more details, see the [Virtual Kubelet security policy](https://github.com/virtual-kubelet/virtual-kubelet/blob/main/SECURITY.md).
